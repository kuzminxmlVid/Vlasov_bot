# Telegram-бот: 3 бесплатных урока, Boosty и отдельный Tribute-канал

Готовый проект для запуска через GitHub → Railway → PostgreSQL.

## Что делает бот

```text
/start
├── Акустика 1
├── Студия 1
├── База 1
└── Получить полный доступ
    ├── Tribute → отдельный закрытый Telegram-канал
    └── Boosty → существующая подписка и канал, подключённый к Boosty
```

После оплаты через Tribute:

1. Tribute отправляет подписанный webhook на Railway.
2. Бот записывает оплату и срок доступа в PostgreSQL.
3. Бот создаёт персональную временную ссылку в отдельный закрытый канал.
4. Пользователь нажимает кнопку и отправляет заявку.
5. Бот проверяет Telegram ID и активную оплату Tribute.
6. Заявка одобряется автоматически.
7. После окончания подписки пользователь автоматически удаляется из канала.

Telegram Bot API не позволяет боту незаметно подписать произвольного пользователя на канал. Поэтому используется максимально близкий и безопасный сценарий: одна кнопка → заявка → автоматическое одобрение.

## Требования к отдельному каналу Tribute

Создайте отдельный **приватный Telegram-канал**, отличный от канала Boosty.

Добавьте основного бота администратором и включите права:

- приглашать пользователей;
- добавлять подписчиков / управлять ссылками;
- блокировать пользователей.

Право на блокировку нужно для автоматического удаления после окончания оплаченного периода.

## Переменные Railway

```env
BOT_TOKEN=токен_бота
ADMIN_IDS=ваш_telegram_id
DATABASE_URL=${{Postgres.DATABASE_URL}}

BOOSTY_URL=https://boosty.to/ссылка-на-нужный-уровень

TRIBUTE_URL=https://t.me/tribute/app?startapp=...
TRIBUTE_API_KEY=секретный_api_ключ_tribute
TRIBUTE_CHANNEL_ID=-1001234567890

TRIBUTE_SUBSCRIPTION_ID=1644
TRIBUTE_PRODUCT_ID=

TRIBUTE_INVITE_HOURS=24
CHANNEL_SYNC_MINUTES=15
LOG_LEVEL=INFO
```

Укажите только один тип предложения Tribute:

- `TRIBUTE_SUBSCRIPTION_ID` — для подписки;
- `TRIBUTE_PRODUCT_ID` — для разовой покупки цифрового товара.

Если оба поля оставить пустыми, бот будет принимать все поддерживаемые предложения аккаунта Tribute, связанного с API-ключом.

## Как узнать ID закрытого канала

Для приватного канала нужен числовой ID формата:

```text
-1001234567890
```

Добавьте бота администратором канала. ID можно получить через служебного Telegram-бота для просмотра сырых данных пересланного сообщения либо временно посмотреть обновления Bot API. После запуска проекта команда:

```text
/channelstatus
```

покажет, удалось ли боту открыть канал и хватает ли ему прав.

## Настройка webhook Tribute

1. Разверните проект на Railway.
2. В Railway откройте `Settings` → `Networking` и создайте публичный домен.
3. В настройках API Tribute укажите:

```text
https://имя-сервиса.up.railway.app/webhooks/tribute
```

4. Проверка Railway:

```text
https://имя-сервиса.up.railway.app/health
```

Ответ:

```json
{"status":"ok"}
```

## Логика доступа

### Новая или продлённая подписка

- доступ записывается в PostgreSQL;
- пользователю отправляется персональная ссылка-заявка;
- если он уже состоит в канале, бот просто подтверждает доступ.

### Отмена автопродления

Пользователь остаётся в канале до даты `expires_at`, которую прислал Tribute.

### Окончание подписки

Фоновая синхронизация проверяет истёкшие доступы каждые `CHANNEL_SYNC_MINUTES` минут и удаляет пользователей из канала.

### Возврат цифрового товара

Пользователь удаляется из канала сразу после webhook о возврате.

### Повторная покупка

Если пользователь раньше был удалён, бот снимает техническую блокировку и выдаёт новую ссылку.

## Админские команды

```text
/admin
/stats
/channelstatus
/syncchannel
/channelinvite TELEGRAM_ID
/access TELEGRAM_ID
```

- `/channelstatus` — проверяет канал и права бота;
- `/syncchannel` — вручную запускает удаление пользователей с истёкшим доступом;
- `/channelinvite TELEGRAM_ID` — повторно отправляет вход пользователю с активной оплатой Tribute;
- `/access TELEGRAM_ID` — показывает состояние доступа в базе.

## Управление уроками

```text
/setlesson acoustic
/setlesson studio
/setlesson base
```

После команды отправьте медиа. Telegram `file_id` сохраняется в PostgreSQL.

Изменить текст:

```text
/settext acoustic Новый текст
```

Удалить медиа:

```text
/clearlesson acoustic
```

Изменить ссылки без нового деплоя:

```text
/setboosty https://boosty.to/...
/settribute https://t.me/tribute/app?startapp=...
```

## Что хранится в PostgreSQL

- пользователи;
- просмотры бесплатных уроков;
- настройки и ссылки;
- события webhook Tribute;
- подписки, покупки, сроки и возвраты;
- созданные ссылки в канал;
- вступления и удаления пользователей.

## Развёртывание

1. Распакуйте архив.
2. Загрузите содержимое в корень GitHub-репозитория.
3. В Railway создайте проект из GitHub.
4. Добавьте PostgreSQL.
5. Добавьте переменные окружения.
6. Создайте публичный домен.
7. Укажите webhook в Tribute.
8. Выполните `/channelstatus`.
9. Проведите тестовую оплату небольшим тестовым тарифом.

Проект автоматически создаёт новые таблицы при запуске. Старую PostgreSQL-базу от предыдущей версии можно оставить.
